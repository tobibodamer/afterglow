# Impulse responses

`detmold_konzerthaus_revc4_r2_stereo.wav` (48 kHz, 32-bit float, stereo, 6.0 s)

Optional measured-hall alternative to the sampler's default synthetic IR (`--set reverb=music/ir/detmold_konzerthaus_revc4_r2_stereo.wav`).
Derived from the Detmold Open Spatial RIR database, Set A, Konzerthaus Detmold, source S1, receiver R2 (audience),
condition RevC4 ("Romantik Musik", room-enhancement system on, nominal RT 2.3 s), open array capsules 4 (left) and 3 (right),
10 cm apart. Changes: the two capsules were taken as L/R, the file was trimmed to 6 s from 5 ms before the direct sound,
faded out over the last 0.5 s and peak-normalised. The sampler additionally removes the direct sound and high-passes it at 60 Hz.

of Music", 149th AES Convention, 2020. Data: https://doi.org/10.5281/zenodo.4007388 (DetmoldSRIR_v01.zip). Modified as described above.
